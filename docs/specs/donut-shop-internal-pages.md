# Donuts: páginas internas

## Objetivo
Completar la presentación del proyecto Front-end Donuts incorporando sus cuatro páginas internas originales.

## Alcance y flujos
Desde la portada de Donuts, las personas pueden navegar a Galería, Lugares, Recetas y Contacto, y volver a Inicio o cambiar entre secciones. Las rutas deben funcionar directamente y mediante historial SPA. Se reutilizan los recursos del repositorio original.

## Criterios de aceptación
- Existen rutas propias para las cuatro secciones y enlaces visibles entre ellas.
- Cada sección presenta su contenido e imágenes correspondientes en español e inglés.
- Contacto conserva campos requeridos y etiquetas accesibles.
- La navegación es operable con teclado, responsiva y conserva el título de documento.

## Requisitos no funcionales
Usar React Router, Sass, HTML semántico y contenido bilingüe centralizado/localizable; mantener accesibilidad WCAG 2.2 AA.

## Exclusiones
No se implementa envío de formularios, mapa interactivo, integración con Bootstrap ni cambios en el sitio externo.
