# Especificación: enlace «Volver a categoría»

## Objetivo

Simplificar el texto en español del enlace de retorno de las fichas de proyecto para que muestre «Volver a categoría».

## Alcance

- Actualizar la traducción española usada por el enlace de retorno de una ficha de proyecto.
- Conservar destino, icono, comportamiento y traducciones de otros idiomas.

## Flujo de usuario

Al abrir una ficha de proyecto en español, la persona ve «← Volver a categoría» y puede activar el enlace para regresar a la categoría correspondiente.

## Criterios de aceptación

- El enlace de retorno de todas las fichas de proyecto en español dice «Volver a categoría».
- El enlace conserva su ruta de retorno a la categoría del proyecto.
- La traducción inglesa no cambia.

## Requisitos no funcionales

- Se conserva el enlace nativo, su nombre accesible, la navegación con teclado y el foco existente.

## Exclusiones

- No se modifican rutas, estilos ni el contenido de las fichas de proyecto.
